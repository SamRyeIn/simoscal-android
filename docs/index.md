# simoscal for Android

An open-source Android app for editing Simos18 ECU calibration files on-device.
It declares no Android permissions at all — including no internet permission —
so it cannot send anything anywhere.

- **[Privacy policy](privacy-policy.html)**
- [Source code](https://github.com/SamRyeIn/simoscal-android) (GPL-3.0)
- [The `simoscal` library](https://github.com/SamRyeIn/simoscal) it embeds
